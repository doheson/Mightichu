# @mightichu/bots

AI 봇. 입력은 **리댁션된 View** 뿐이라 구조적으로 치팅이 불가능하다.

```ts
type Bot<View, Action> = {
  decide(ctx: { me, view, legal, rng }): Action;   // View 만 받는다 — State 가 아니다
  wants?(ctx): boolean;                            // 지금 꼭 둬야 하는가
}
```

## 레벨

| | 용도 | 상태 |
|---|---|---|
| **L1 랜덤** | 엔진 테스트 하네스 | ✅ |
| **L2 휴리스틱** | 실제 대전 상대 | ✅ |
| L3 MCTS + 결정화 | 강한 AI | ⬜ 별도 과제 |

## 임계값은 추측이 아니라 측정으로 잡는다

휴리스틱의 상수를 감으로 정하면 틀려도 모른다. 전부 자동 대국으로 재서 맞췄다.

### 마이티 — 공약 추정

점수를 가져오는 경로는 둘뿐이다: 기루다로 베어내기, 내 무늬 높은 카드로 직접 먹기.
그래서 **기루다 장수**가 거의 전부다.

기준 상수를 7 로 뒀을 때와 6 으로 내렸을 때 (500판):

| 기준 | 여당 성공률 | 평균 공약 | 평균 획득 | 중앙 차 |
|---|---|---|---|---|
| 7 | 46.0% | 15.18 | 14.04 | −1 |
| **6** | **57.2%** | **14.20** | **14.00** | **0** |

한 장씩 과대 공약이던 것을 바로잡으니 손익분기 위로 올라왔다.

### 티츄 — 선언 판단

`planHand` 로 손패를 낼 단위로 쪼개 **lotCount**(손을 비우는 데 필요한 횟수)와
**control**(용·봉황·에이스·폭탄 개수)을 센다. 600판 측정 (±100 이므로 손익분기 50%):

| 조건 | 선언 수 | 성공률 | 판당 EV |
|---|---|---|---|
| lot≤3 ctrl≥2 | 13 | 69.2% | +0.8 |
| **lot≤5 ctrl≥3** | **53** | **52.8%** | **+0.5** |
| lot≤5 ctrl≥2 | 150 | 48.7% | −0.7 |
| lot≤6 ctrl≥3 | 115 | 46.1% | −1.5 |

표본이 받쳐주면서 +EV 인 조건을 택했다.

**선언 시점도 측정으로 바뀌었다.** 교환 **전** 손패로 재면 받을 3장을 모르는 채
재는 셈이라 성공률이 37% 로 떨어진다. 룰상 첫 카드를 내기 전이면 언제든 선언할 수 있으므로
교환이 끝난 뒤에 판단한다.

> 솔직한 평가: 티츄 선언 +0.5/판은 **미미하다.** 병목은 선언 규칙이 아니라 플레이 실력이다.
> 봇이 더 잘 두게 되면 같은 조건에서 성공률이 올라가고, 그때 기준을 완화하면 된다.

## L2 가 하는 것

**공통**
- **팀 패를 밟지 않는다.** 파트너가 이기고 있으면 넘긴다 (200판 자동 대국으로 0회 검증)
- **카운팅** — `view.playedCards`(공개 정보)를 보고 내 카드가 최고인지 안다

**티츄** (`tichu/plan.ts`)
- **핸드 분할** — 14장을 낼 단위로 미리 쪼갠다. 스트레이트가 될 카드를 홑장으로 흘리지 않는다
- 폭탄은 깨지 않고 통째로 남긴다
- 교환: 파트너에게 센 카드, 상대에게 약한 카드
- 파트너가 티츄를 부르면 **길을 터준다** (점수 큰 트릭만 챙기고 나머지는 양보)
- 아웃오브턴 폭탄은 큰 트릭에서만

**마이티**
- 기루다 장수 기반 공약 추정
- 확실히 먹을 수 있는 카드(같은 무늬 상위가 전부 나감)로 리드
- 아는 범위에서 아군 추론 (프렌드가 숨어 있어 범위가 좁다)

## 아직 못 하는 것

정직하게 적어둔다.

- 티츄 핸드 분할이 **탐욕적**이다. 완전 탐색이 아니라 긴 조합부터 가져간다
- 상대 손패 추론이 없다 (누가 어떤 무늬가 없는지 추적하지 않는다)
- 마이티 프렌드 추론이 거의 없다 — 공개된 뒤에만 안다
- 봉황·용 사용 시점이 단순하다
