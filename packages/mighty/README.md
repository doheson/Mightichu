# @mightichu/mighty

마이티(5인) 룰 엔진. 순수 함수, 런타임 의존성은 `@mightichu/core` 뿐.

규칙 출처와 확정된 변형은 [docs/rules-mighty.md](../../docs/rules-mighty.md) 참고.

| 모듈 | 역할 |
|---|---|
| `cards.ts` | 53장 덱, 카드 토큰, 마이티·조커콜 결정, 점수카드, 비딜 ½점 공식 |
| `bidding.ts` | 비드 서열(같은 수면 NT 우위), 기루다 변경 요구 공약 |
| `trick.ts` | 강약 판정, 트릭 승자, 합법 제출 카드(조커콜 강제·마이티 강제·첫트릭 기루다 금지) |
| `scoring.ts` | 점수 공식, 배수 누적(런·백런·NT·노프렌드), 제로섬 지급 |
| `engine.ts` | `GameEngine` 구현 — 상태 전이와 리댁션 |

## 상태 흐름

```
MISDEAL? → BIDDING → KITTY → FRIEND → PLAY(10트릭) → DONE
```

`MISDEAL` 은 재딜 자격자(½점 이하)가 있을 때만 거친다.
재딜·전원패스는 라운드를 무효화한다 (`outcome.kind === 'REDEAL'`, 전원 0점).
새 시드로 다시 `init` 하는 건 상위 매치 계층의 몫.

## 구현에서 주의한 지점

- **카드 토큰은 2자리 0 패딩** (`S02`, `S14`) — 리댁션 테스트의 문자열 검사가
  `S2` ⊂ `S12` 같은 거짓 양성을 내지 않게.
- **♠A 의 정체가 기루다에 따라 바뀐다** — 기루다가 스페이드면 ♠A 는 일반 기루다이고
  ♦A 가 마이티다. 테스트 픽스처를 짤 때 가장 자주 틀리는 지점.
- **기루다 변경과 카드 버리기를 별개 액션으로 분리** — 한 액션으로 묶으면
  `legalActions` 가 C(13,3) × 변경지 = 수천 가지로 폭발한다.
- **버린 3장의 점수카드는 여당 몫** — 속성 테스트로는 안 잡혀서 대본 테스트로 덮었다.
