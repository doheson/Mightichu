# 티츄 (Tichu) 규칙 정리

> 출처: Fata Morgana / ABACUSSPIELE **공식 영문 룰북 PDF**(전문 확보), Board Game Arena, Wikipedia
> 마이티와 달리 티츄는 **공식 룰북이 명확**해서 변형 여지가 적다.

## 1. 구성

- 플레이어: **4명, 2:2 팀**. 파트너는 **마주 앉음**.
- 덱: **56장** = 4개 무늬(♠ ♦ ♥ ♣) × 13장 + 특수카드 4장

### 용어 (프로젝트 표준)

특수카드는 **한국어 이름**을 정식 명칭으로 쓴다. 영문 원명은 참고용.

| 한국어 (정식) | 영문 원명 | 코드 식별자 | 점수 |
|---|---|---|---|
| **용** | Dragon | `DRAGON` | +25 |
| **봉황** | Phoenix | `PHOENIX` | -25 |
| **개** | Dog | `DOG` | 0 |
| **참새** | Mah Jong (麻雀) | `SPARROW` | 0 |

- 참새: 원명 麻雀(마작)이 중국어로 **참새**를 뜻하고 카드 그림도 참새라서, 마작 게임과 혼동되지 않게 **참새**로 통일.
- 무늬는 **표준 트럼프**를 쓴다: **♠ 스페이드 / ♦ 다이아 / ♥ 하트 / ♣ 클로버** (`S` / `D` / `H` / `C`)
  - 원작은 옥·검·탑·별이지만 익숙한 무늬가 읽기 쉽고, 마이티와 토큰도 같아진다
- 특수카드는 UI 에서 **그림**으로 보여준다 (용 / 봉황 / 개 / 참새).
  한자는 한눈에 구분되지 않아 쓰지 않는다.
  이모지도 쓰지 않는다 — 플랫폼마다 모양이 달라지고 **봉황은 아예 해당 이모지가 없다**.
  대신 인라인 SVG 로 직접 그린다(`TichuCard.tsx`). 전용 일러스트로 교체할 자리다
- 서열: A > K > Q > J > 10 > 9 > ... > 2 (10은 9와 J 사이)
- **진행 방향: 반시계(오른쪽)** ← 공식 룰북 명시. 흔한 구현 실수 포인트.

### 점수

| 카드 | 점수 |
|---|---|
| 5 | **5점** |
| 10, K | 각 **10점** |
| 용 | **25점** |
| 봉황 | **-25점** |
| 그 외 | 0점 |

→ 한 라운드 총점 **100점** (고정).

## 2. 딜과 입찰(티츄 선언)

딜은 **두 단계**로 나뉘고, 입찰 종류가 단계에 대응한다.

### 1단계 — 8장 배분 → **라지 티츄(Grand Tichu, ±200)**
- 각자 **8장**만 보고 선언 여부 결정.
- 공식 룰북 표현으로는 "**9번째 카드를 받기 전까지**" = 8장을 본 상태.
- 배팅액 **200점**. 가장 공격적인 선언.

### 2단계 — 남은 6장 배분(총 14장) → **스몰 티츄(Tichu, ±100)**
- 14장을 다 받은 뒤, **자기 첫 카드를 내기 전까지 아무 때나** 선언 가능.
- "아무 때나"의 범위가 넓다 — 구현 시 주의:
  - **카드 교환 전에도** 선언 가능 (파트너에게 "좋은 카드 보내라"는 신호가 됨 — 공식 룰북이 명시하는 용법)
  - **다른 사람 차례 중에도** 선언 가능 (내 첫 카드만 아직 안 냈으면 됨)
- 배팅액 **100점**.

### 공통 규칙
- **개인 선언.** 파트너와 상의 금지. **선언자 본인이 1등**해야 성공 — 파트너가 1등해도 안 됨.
- 성공 → 팀에 +100 / +200, 실패 → **-100 / -200**
- 일반 카드 점수와 **별도로 가감**. 더블윈 200점일 때도 티츄 가감은 그대로 적용.
- 구현 관례: 라지 티츄를 선언한 사람은 스몰 티츄를 추가 선언하지 않음(하나의 배팅). 룰북에 명문 규정은 없음.

## 3. 카드 교환

- 각자 **3장**을 골라 **다른 3명에게 각 1장씩** 비공개로 전달.
- 자기 3장을 모두 넘긴 뒤에야 받은 카드를 볼 수 있음.

## 4. 조합 (낼 수 있는 형태)

| 조합 | 설명 |
|---|---|
| 싱글 | 1장 |
| 페어 | 같은 끗 2장 |
| 연속 페어 | 연속된 끗의 페어 2개 이상 (예: 55-66) |
| 트리플 | 같은 끗 3장 |
| 풀하우스 | 트리플 + 페어 (**트리플의 끗**으로 비교) |
| 스트레이트 | 연속 **5장 이상** (무늬 무관) |

**핵심 제약: 같은 형태 · 같은 장수만 비교 가능.**
- 싱글은 더 높은 싱글로만. 페어 2개 묶음은 더 높은 페어 2개 묶음으로만.
- 8장 스트레이트는 **8장** 스트레이트로만 이길 수 있음.
- 유일한 예외는 **폭탄**.

## 5. 특수 카드 4장

### 참새 (Mah Jong / 麻雀) — 0점
- 가진 사람이 **라운드 첫 리드**. (참새를 꼭 낼 필요는 없음)
- 값 **1**, 게임 내 최약. **스트레이트에서 1로 사용** 가능 (1-2-3-4-5).
- 낼 때 **"소원(wish)"**: 끗 하나를 지정(2~A, 특수카드 불가).
  - 그 카드를 가졌고 **합법적 조합으로 낼 수 있는** 다음 플레이어는 **반드시 내야 함** (필요하면 폭탄으로라도).
  - 못 내면 자유롭게 플레이/패스. **소원은 누군가 이행할 때까지 유지.**
  - 실수로 소원을 이행하지 않으면 → **상대팀이 더블윈 200점** 처리.

### 개 (Dog) — 0점
- 트릭 가치 없음, 트릭에 낼 수 없음.
- **리드할 때만** 낼 수 있고, 즉시 **리드권이 파트너에게** 넘어감 (트릭 없음).
- 파트너가 카드가 없으면 파트너의 **오른쪽** 사람에게.
- **개를 낸 순간 전환은 즉시 — 폭탄 끼어들 틈 없음.**

### 용 (Dragon) — **+25점**
- **최강 싱글**. 에이스도, 에이스 위의 봉황(A½)도 이김. **폭탄만** 이길 수 있음.
- **스트레이트에 사용 불가.**
- 용으로 트릭을 이기면 그 트릭(25점 포함)을 **상대팀 한 명에게 줘야 함**.
- 단 **폭탄으로 깨진 트릭은 주지 않음**.

### 봉황 (Phoenix) — **-25점**
- 싱글로 낼 때: 직전 싱글보다 **0.5 높은 값**. (8 위에 내면 8½ → 9 이상으로 제압 가능)
- 에이스는 이기지만 **용은 못 이김**.
- **리드로 낼 때 값은 1½.**
- 조합에서는 **2~A 아무 끗의 와일드카드**로 사용 가능.
- **폭탄으로는 사용 불가.**

## 6. 폭탄 (Bomb)

- 종류: **포카드**(같은 끗 4장), **스트레이트 플러시**(같은 무늬 연속 5장 이상)
- **순서를 무시하고(아웃 오브 턴) 아무 때나** 낼 수 있음. 모든 조합을 이김.
- 폭탄 간 비교: **장수가 많은 쪽이 강함** → 스트레이트 폭탄 > 포카드. 같은 종류면 끗 비교.
- 3명이 패스한 뒤라도 **트릭을 걷기 전**이면 폭탄 가능. **리드로도** 낼 수 있음.
- **자기 팀 트릭에도 폭탄 가능.**
- 폭탄은 **리드권을 바꾸지 않음** — "트릭을 먹은 사람의 리드권은 신성하다".

## 7. 트릭 진행

- 다음 플레이어는 **패스** 또는 **같은 형태의 더 높은 조합**.
- 패스했어도 **다음 차례에 다시 낼 수 있음**.
- **3명이 연속 패스**하면 마지막으로 낸 사람이 트릭을 걷고 새로 리드.
- 손이 빈 사람은 그 라운드 종료 — 리드권은 **오른쪽**으로 넘어감 (그 사람도 비었으면 계속 오른쪽).
- 마지막 카드로 트릭을 먹어도 유효. 용으로 먹었으면 라운드 끝나기 전에 상대팀에 넘김.

## 8. 라운드 종료와 점수

**라운드는 한 명만 카드가 남은 순간 즉시 종료.**

카드가 남은 그 플레이어는:
- **손에 남은 카드 → 상대팀에게**
- **자기가 모은 트릭 전부 → 1등(가장 먼저 턴 사람)에게**

그 뒤 각 팀의 카드 점수를 합산 + 티츄 선언 가감.

### 더블윈 (One-Two)
한 팀이 **1등과 2등을 모두** 차지하면 → 즉시 **200점**, 라운드 종료.
**카드 점수 계산 없음.** (티츄 선언 가감은 적용)

### 게임 종료
- 먼저 **1000점**에 도달한 팀 승리.
- 같은 라운드에 양 팀이 동시 도달하면 **점수 높은 팀** 승리.

## 9. 구현 시 주의 포인트

- [ ] 진행 방향 **반시계(오른쪽)** — 공식 룰
- [ ] 봉황 0.5 값 처리 → 내부 서열을 정수 2배(또는 소수) 스케일로 설계
- [ ] 폭탄의 **아웃 오브 턴** 처리 → 턴 엔진을 인터럽트 가능하게 설계
- [ ] 소원(wish) **강제 이행 검증** — "합법적 조합으로 낼 수 있는가" 판정이 가장 까다로움
- [ ] 개(Dog)는 폭탄 끼어들 틈 없이 즉시 전환
- [ ] 용 트릭 양도 대상 선택 UI / 폭탄으로 깨진 경우 예외
